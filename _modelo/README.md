## Como instalar

No Claude Code:

```
/plugin marketplace add https://github.com/kapstanhq/oficina.git
/plugin install __slug__@kapstan-oficina
```

Depois, uma vez:

```
/__slug__:comecar
```

A primeira pergunta é em que pasta do seu computador a <<preencher: base>> vai
morar. Daí em diante ela pergunta uma coisa de cada vez e salva conforme avança.

## As ferramentas

| Comando | O que faz |
|---|---|
| `/__slug__:comecar` | Monta a pasta de trabalho e testa o que está conectado |
| `/__slug__:importar-a-conversa` | Traz para a pasta o que já está no seu WhatsApp |
| `/__slug__:primeira-skill` | <<preencher: o que ela faz, numa linha — e troque primeira-skill pelo nome que a pasta ganhar>> |
| `/__slug__:o-que-fazer-hoje` | Monta a lista do dia |
| `/__slug__:retomar-contato` | Acha quem sumiu e escreve a mensagem de volta |
| `/__slug__:cobrar-o-que-falta` | Cobra quem ficou de mandar e não mandou |
| `/__slug__:compartilhar-com-<<preencher: pessoa>>` | Monta a vista do que a outra pessoa pode ver |
| `/__slug__:organizar-<<preencher: pasta-base>>` | Guarda o que chegou e arquiva o que morreu |
| `/__slug__:laudo-da-<<preencher: pasta-base>>` | Diz o que está errado, sem mexer em nada |
| `/__slug__:completar-ficha` | Procura o que falta na ficha nas fontes que você tem, e grava com a origem |

E uma que o painel chama por você: `/__slug__:gravar-o-que-marquei` grava o que
você marcou nele, e mais nada.

Você também pode escrever o que quer, em português, e a ferramenta certa é
escolhida sozinha.

## Onde ficam os seus dados

Numa pasta do seu computador, escolhida no `/__slug__:comecar`. São arquivos de
texto comuns, e nenhum passa por servidor da Kapstan.
